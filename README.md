# 我的学习平台 · 四六级 + C 语言

一个**纯前端**的个人学习工作台，单文件驱动（`index.html`，约 210 KB），打开即用，不需要构建、不需要装依赖、断网也能跑。

带一只 3D 鲸鱼娘桌宠陪学：会摸头、会讨吃的、会催你别摸鱼、会因为你背完单词而高兴。

---

| 🏠 仪表盘 | 学习天数、四六级双进度条、番茄统计、最近测验 |

## 鲸鱼娘桌宠

互动内核来自 [`Sutera-Diffusus/dsh-whale-musume`](https://github.com/Sutera-Diffusus/dsh-whale-musume)（MIT），原样引入 `assets/whale-moe-core.js`，再由 `assets/whale/pet-brain.js` 适配到本项目的 3D 鲸鱼上。

- **620 条台词**，覆盖问候、工作、互动、关键词回复、天气、时段、羁绊等场景
- **好感度 / 心情 / 饱食度** 三套独立成长数值，500 好感升一级
- **40 个成就**（从内核 45 个中剔除了本项目无法触发的 5 个，保证可以集满）
- **接蛋糕小游戏**：30 秒，🍰+10 / ⭐+30 / 💣−20，带连击

### 操作

| 动作 | 效果 |
|---|---|
| 单击 | 摸她（按点击位置分为头 / 肚子 / 尾巴，反应不同） |
| 连点 3 下 | 比心彩蛋 |
| 双击 | 打开聊天面板 |
| 右键 / 手机长按 | 菜单（投喂、小游戏、成长、聊天、打招呼） |
| 拖拽 | 甩到别处（会飞回来） |

### 学习联动

掌握单词 +8 好感、番茄钟完成 +26、待办勾选与测验交卷各有对应台词；连续 25 分钟没动会被"抓包"。

## 本地运行

### 方式一：直接打开

双击 `index.html` 即可。所有资源都是相对路径，**零外部 CDN 依赖**。

### 方式二：带云端存档（可选）

```bash
python server.py            # 默认 8000 端口
# 或指定端口
PORT=8080 python server.py
```

零依赖，纯 Python 标准库。启动后访问 <http://localhost:8000>。

它会额外提供 `/api/state` 接口，把学习进度存到 `data/state.json`（每次覆盖前自动备份到 `data/backups/`，保留最近 20 份）。此时进度可以跨浏览器、跨设备同步。

启动时前端会先探测 `/api/state`：

- **可用** → 与本地缓存比较 `savedAt`，取较新的那份
- **不可用**（例如部署在 GitHub Pages）→ 自动降级为 `localStorage`，不报错、不发无用请求

## 部署

本项目是纯静态站点，直接由 GitHub Pages 托管：

**https://cyc20261.github.io/study-platform/**

Pages 环境没有 Python，因此线上走 `localStorage` 单机存档（`server.py` 只在本地运行时生效）。学习数据保存在浏览器中，**换浏览器或清缓存会丢失进度**。

要更新线上内容，推 `main` 分支即可，Pages 会自动重新发布。

## 说明

- `data/`、`shots/`、`*.bak.*` 已在 `.gitignore` 中排除，个人学习进度不会被推到仓库。
